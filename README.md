# DriveMart

Jogo web no estilo dos clássicos de direção do PS1, em modo de direção livre, onde cada prédio da cidade pode ser comprado via Pix, personalizado com imagem ou GIF na fachada e ganhar um link de entrada.

O guia completo de configuração e deploy fica neste arquivo ao fim do desenvolvimento.

## Desenvolvimento

```bash
npm install
npm run dev        # jogo em http://localhost:5173
npm run dev:all    # jogo + emuladores do Firebase
npm test           # testes unitários
```
